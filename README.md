# Surge 油价面板

独立重写的 Surge generic 脚本，不复制 cc63/Surge 原脚本（上游仓库未附可用许可证）。原模块依赖的 qiyoujiage.com 省页在 2026-10-28 仍展示 2026-09-26 的日期，并把已过期的 10 月 15 日调价提示显示在「今日油价」下。

## 数据与范围

- 31 省：从 HTTPS `www.icauto.com.cn/oil/price_{行政区划代码}_0.html` 获取省级 92/95 号汽油、0 号柴油，核对页面日期；该站不提供 98 号汽油，不编造。显示最近一次实际调价日期，不用动态的「今日」字样证明新价格。
- 城市参数如 `shanxi-3/xian`：沿用原站城市页（HTTP），核对页面自己的价格日期，显示 98 号汽油及非加密来源提示；它可能落后于省级数据。
- 下次调价窗口及吨价取[金联创成品油实时页面](https://oil.315i.com/chengpy.html)，核实第几个工作日的日期、尚未过去的窗口与预测值；每升**统一范围**仅在[同日媒体报道](https://m.sohu.com/a/1093928064_121455647)和吨价一致时采用。面板每个油号显示「现价 → 调后粗估区间」，另以一行显示调价窗口与吨价、一行显示日期及「粗估非官方」；调后粗估区间 = 本地现价 + 全油品升价范围，**不是各油号准确预测价，更非政府公布新价格**。预测来源过期、窗口已过或任一校验失败时显示“下次调价：暂无可核实预测”，绝不继续呈现旧预测。两来源网页结构可能改变；网站对 iOS Surge 的可访问性待设备验收。
- 没有可信现价时展示失败，而不是回退到无日期旧数据。油价仅供参考，以当地加油站报价为准。
- 默认山东 `shandong`；陕西是 `shanxi-3`，山西是 `shanxi`。省级与城市价不可混为一谈。

安装：Surge 导入本仓库 `main/QiYou.sgmodule` 的 Raw 链接，启用面板，按需改参数。若原模块仍在运行，先禁用原模块，避免两个同名 QiYou 面板冲突。脚本 URL 已加版本参数以绕开已有脚本缓存；**必须在 Surge 对模块执行更新后再刷新面板**，单刷新面板不保证模块新配置已获取。如果仍只有「最近调价」而没有「下次」或「下次调价：暂无可核实预测」，说明在手机端执行的仍是旧脚本，请核对模块 URL 和已启用模块列表；并非用户设备实测。

测试：`node --check QiYou.js && node test.js`。仅本地脚本及 HTTP 访问验证，不代表 Surge 真机、上游准确性或官方调价确认。原作者参考来源：https://github.com/cc63/Surge/tree/main/Module/Panel/QiYou/Moore 。
