# Surge 油价面板

独立重写的 Surge generic 脚本，不复制 cc63/Surge 原脚本（上游仓库未附可用许可证）。原模块依赖的 qiyoujiage.com 省页在 2026-10-28 仍展示 2026-09-26 的日期，并把已过期的 10 月 15 日调价提示显示在「今日油价」下。

## 数据与范围

- 31 省：从 HTTPS `www.icauto.com.cn/oil/price_{行政区划代码}_0.html` 获取省级 92/95 号汽油、0 号柴油，并解析页面日期；该站不提供 98 号汽油，不编造。页面日期不等于价格调整日期；面板价格仅供参考。
- 城市参数如 `shanxi-3/xian`：沿用原站城市页（HTTP），核对页面自己的价格日期，显示 98 号汽油及非加密来源提示；它可能落后于省级数据。
- 面板固定顺序：**当前价格 → 预计调价日期 → 各油号预计调价幅度 → 预计调后价格**，末行保留“预测仅供参考，以正式公告为准”，不使用箭头合并。
- 预计调价窗口来自[金联创成品油实时页面](https://oil.315i.com/chengpy.html)，校验监测日期与未来窗口。当前来源只有标准品吨价，**并没有可核实的分油号元/升预测**，因此各油号预计涨幅及调后价显示“待更新”。已移除此前将媒体统一范围套到各油号的计算；不编造精确数值，也不将吨价直接换成升价。窗口过期、来源不可用或校验失败时，调价日期也显示“待更新”。网站结构及 Surge 网络可访问性仍需设备验收。
- 没有可信现价时展示失败，而不是回退到无日期旧数据。油价仅供参考，以当地加油站报价为准。
- 默认山东 `shandong`；陕西是 `shanxi-3`，山西是 `shanxi`。省级与城市价不可混为一谈。

安装：Surge 导入本仓库 `main/QiYou.sgmodule` 的 Raw 链接，启用面板，按需改参数。若原模块仍在运行，先禁用原模块，避免两个同名 QiYou 面板冲突。脚本 URL 已加版本参数以绕开已有脚本缓存；**必须在 Surge 对模块执行更新后再刷新面板**，单刷新面板不保证模块新配置已获取。四分区版应显示「当前价格」「预计调价日期」「预计调价幅度」「预计调后价格」。若仍显示箭头或只有「最近调价」，请核对模块 URL 和已启用模块列表，可能仍执行旧脚本；本仓库测试不等于用户设备实测。

测试：`node --check QiYou.js && node test.js`。仅本地脚本及 HTTP 访问验证，不代表 Surge 真机、上游准确性或官方调价确认。原作者参考来源：https://github.com/cc63/Surge/tree/main/Module/Panel/QiYou/Moore 。
