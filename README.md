# Surge 油价面板

独立重写的 Surge generic 脚本，不复制 cc63/Surge 原脚本（上游仓库未附可用许可证）。原模块依赖的 qiyoujiage.com 省页在 2026-10-28 仍展示 2026-09-26 的日期，并把已过期的 10 月 15 日调价提示显示在「今日油价」下。

## 当前排版（20261029-official-adjustment-1）

仅展示 92、95 号汽油，现价和预计调后价格分别逐行显示；下次调价日期、统一预计涨幅各占一行。正常面板不返回 icon / icon-color，去掉橙色油枪。Surge 是否回收图标空白及实际换行仍需真机验收。移除柴油和城市 98 号仅影响展示，数据获取、完整性校验、预测校验与失败保护保持不变。错误状态保留警告图标。

## 数据与范围

- 31 省：从 HTTPS `www.icauto.com.cn/oil/price_{行政区划代码}_0.html` 获取省级 92/95 号汽油、0 号柴油，并解析页面日期；该站不提供 98 号汽油，不编造。页面日期不等于价格调整日期；面板价格仅供参考。
- 城市参数如 `shanxi-3/xian`：沿用原站城市页（HTTP），核对页面自己的价格日期，显示 92/95 号汽油及非加密来源提示；它可能落后于省级数据。
- 面板固定顺序：**当前价格 → 下次调价 → 预计涨幅 → 预计调后价格**。2026-10-29 国家发改委公布汽油正式涨幅 345 元/吨后，以[海南国际旅游岛商报旧报道](https://view.inews.qq.com/k/20261026A0BD2E00?scene=wap&no-redirect=1)对**同一 345 元/吨估算**的汽柴油统一升价范围 +0.26～0.31 元/升计算面板预计调后价；安徽目前 92 号 8.55→**8.81～8.86**、95 号 9.14→**9.40～9.45**。这是媒体统一估值加法，不是官方逐标号价，末行明确“升价为媒体估算；官方汽油+345元/吨”；不能声称油号精确调价。
- 预计调价窗口来自[金联创成品油实时页面](https://oil.315i.com/chengpy.html)，校验监测日期与未来窗口；2026-10-29 15:03 后该周期优先核对[国家发改委正式公告](https://www.ndrc.gov.cn/xwdt/xwfb/202610/t20261029_1408449_ext.html)内汽油 345 / 柴油 335 元/吨，旧搜狐文章仍报道 410 元/吨时不再展示它；只在[另一篇报道](https://view.inews.qq.com/k/20261026A0BD2E00?scene=wap&no-redirect=1)原文写明 10 月 29 日且吨价恰为 345 元时采用其 +0.26～0.31 元/升估算范围。若官方公告或媒体原文读取失败则隐藏预测，不回退到过期报道。其他周期预测范围来自[同日媒体报道](https://m.sohu.com/a/1093928064_121455647)，必须与机构吨价、预测日期、调价窗口一致。此前面板预计涨幅是**媒体对汽柴油给出的统一预测范围，并不是92/95号的独立精确测算**；92/95号预计调后价格为各现价加此范围，不能当作官方公布价。窗口过期或来源校验失败显示“预测暂不可用”，不展示陈旧数值，不把吨价直接换成升价。网站结构及 Surge 网络可访问性仍需设备验收。
- 没有可信现价时展示失败，而不是回退到无日期旧数据。油价仅供参考，以当地加油站报价为准。
- 默认山东 `shandong`；陕西是 `shanxi-3`，山西是 `shanxi`。省级与城市价不可混为一谈。

安装：Surge 导入本仓库 `main/QiYou.sgmodule` 的 Raw 链接，启用面板，按需改参数。若原模块仍在运行，先禁用原模块，避免两个同名 QiYou 面板冲突。脚本 URL 已加版本参数以绕开已有脚本缓存；**必须在 Surge 对模块执行更新后再刷新面板**，单刷新面板不保证模块新配置已获取。紧凑版应显示「当前价格」「下次调价」「预计涨幅」「预计调后价格」，仅含92/95号且没有橙色油枪。若仍显示箭头或只有「最近调价」，请核对模块 URL 和已启用模块列表，可能仍执行旧脚本；本仓库测试不等于用户设备实测。

测试：`node --check QiYou.js && node test.js`。仅本地脚本及 HTTP 访问验证，不代表 Surge 真机、上游准确性或官方调价确认。原作者参考来源：https://github.com/cc63/Surge/tree/main/Module/Panel/QiYou/Moore 。
