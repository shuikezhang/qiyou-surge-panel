# Surge 油价面板

独立重写的 Surge generic 脚本，不复制 cc63/Surge 原脚本（上游仓库未附可用许可证）。原模块依赖的 qiyoujiage.com 省页在 2026-10-28 仍展示 2026-09-26 的日期，并把已过期的 10 月 15 日调价提示显示在「今日油价」下。

## 当前排版（20261029-generic-adapter-1）

仅展示 92、95 号汽油，现价和预计调后价格分别逐行显示；下次调价日期、统一预计涨幅各占一行。正常面板不返回 icon / icon-color，去掉橙色油枪。Surge 是否回收图标空白及实际换行仍需真机验收。移除柴油和城市 98 号仅影响展示，数据获取、完整性校验、预测校验与失败保护保持不变。错误状态保留警告图标。

## 数据与范围

- 31 省：从 HTTPS `www.icauto.com.cn/oil/price_{行政区划代码}_0.html` 获取省级 92/95 号汽油、0 号柴油，并解析页面日期；该站不提供 98 号汽油，不编造。页面日期不等于价格调整日期；面板价格仅供参考。
- 城市参数如 `shanxi-3/xian`：沿用原站城市页（HTTP），核对页面自己的价格日期，显示 92/95 号汽油及非加密来源提示；它可能落后于省级数据。
- 面板固定顺序：**当前价格 → 下次调价 → 预计涨跌 → 预计调后价格**；上涨、下跌、不调整均可显示，无图标，仅 92/95 号。
- 动态机构入口：[金联创成品油滚动页](https://oil.315i.com/chengpy.html)。先解析公告栏，失败再解析同页日期/涨跌表；先去标签、脚本、空白及常见实体，不依赖标签属性或某轮固定数字。窗口必须尚未生效，监测日期不得未来或距今超过 4 天，监测日至生效窗口小于 16 天，支持跨月跨年。机构网站不可用时不以无日期的旧新闻充数。
- 动态官方入口：[发改委新闻栏目](https://www.ndrc.gov.cn/xwdt/xwfb/)。与机构请求并行，按北京时间**当天**日期找到成品油公告再取正文，不写死单篇链接。支持普通上/下调、调控后实际涨跌、不调整；存在“应调”和“实际调”时只用实际值。发现正式文章却读取失败或不能确认实际调幅，关闭预测，不回退到可能已失效的机构值。当天官方公告可独立工作，不要求机构页面先成功。若当天无公告或栏目不可用则机构预测独立工作，底部如实标注“机构预测”。
- **每升模型估算（非官方，也不再声称媒体预测）**：为摆脱每轮新闻依赖，采用可解释经验区间 `abs(汽油元/吨) × [0.00075, 0.00090]` 并四舍五入到分。例如 345→0.26～0.31 元/升，410→0.31～0.37 元/升；这个比例是简化启发式，不是有官方保证的换算关系或统计置信区间，不能当作各标号、各省的准确调价。92/95 号分别在自己的当前价上加/减同一区间；下调按最低到最高重新排序，不调整保持原价。末行始终写“升价为模型估算”，并注明吨价是官方还是机构预测。当前 345 元/吨例中，安徽预计 92 号 8.81～8.86、95 号 9.40～9.45。
- **适配边界**：不再每轮改日期和新闻链接，但不是万能爬虫；两个长期来源都失效、网站反爬或大改版、未来新公告句式超出解析规则时仍可能不可用。窗口过期后不再用该轮涨幅加到已调整的现价上，也不会伪造下一轮预测。没有可靠数据就显示“预测暂不可用”，不缓存跨周期旧预测。Surge 真机访问仍需设备侧验收。
- 没有可信现价时展示失败，而不是回退到无日期旧数据。油价仅供参考，以当地加油站报价为准。
- 默认山东 `shandong`；陕西是 `shanxi-3`，山西是 `shanxi`。省级与城市价不可混为一谈。

安装：Surge 导入本仓库 `main/QiYou.sgmodule` 的 Raw 链接，启用面板，按需改参数。若原模块仍在运行，先禁用原模块，避免两个同名 QiYou 面板冲突。脚本 URL 已加版本参数以绕开已有脚本缓存；**必须在 Surge 对模块执行更新后再刷新面板**，单刷新面板不保证模块新配置已获取。紧凑版应显示「当前价格」「下次调价」「预计涨跌」「预计调后价格」，仅含92/95号且没有橙色油枪。若仍显示箭头或只有「最近调价」，请核对模块 URL 和已启用模块列表，可能仍执行旧脚本；本仓库测试不等于用户设备实测。

测试：`node --check QiYou.js && node test.js`。仅本地脚本及 HTTP 访问验证，不代表 Surge 真机、上游准确性或官方调价确认。原作者参考来源：https://github.com/cc63/Surge/tree/main/Module/Panel/QiYou/Moore 。
